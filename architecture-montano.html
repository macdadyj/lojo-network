Field architecture

Montano remote cattle trap — how LOJO fits

A managed private network path for the latch. Eyes stay in the camera apps ranchers already use. Control is a simple browser page once the phone is on LOJO.

8+ years remote New Mexico 600+ cattle 150+ wild horses Cell + Wi‑Fi or Starlink

Four pieces

Same private network whether the trap site rides cellular or Starlink.

1. Trap site

A small weatherproof computer at the pen drives a spring-loaded gate latch. On boot it joins the LOJO private network and waits for a latch command — nothing more.

2. Rancher phone

Connect to LOJO with the VPN app. Watch the pen in the security camera app. Flip the latch from a browser control page. Video and latch stay separate on purpose.

3. LOJO private network

The private path that carries both the phone and the trap computer. We set it up and keep it running so the ranch does not become the IT department.

4. Latch control page

A simple cloud control screen that only talks to allowlisted LOJO devices. It turns a relay on or off to trip the latch. It is not the video system.

Operator flow

See

Camera app shows cattle or horses enter the pen.

Decide

Rancher confirms on the phone — already on LOJO.

Act

Browser control page sends the latch command to the trap computer.

Catch

Spring gate closes. Animals secured from miles away.

LOJO punchline: the public internet does not carry the control path. Cameras stay familiar rancher tools. LOJO is how you close the gate safely from the road.
